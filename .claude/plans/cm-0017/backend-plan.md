## Summary

Schema-only change. No new routes, controllers, or services. Two categories of changes:

1. **Four missing FK indexes** — add `@@index` on `lessonId` (LessonCompletion), `unitId` (UnitCompletion), `lessonId` (StudentNote), and `assignmentId` (AssignmentCompletion).
2. **Audit timestamps** — add `createdAt @default(now())` and `updatedAt @updatedAt` to `Unit`, `Lesson`, `LessonResource`, `LessonTool`, and `AssessmentQuestion`.

A single Prisma migration covers all changes.

## Folder Layout

No new files. Only existing files are modified:

```

```

### Migration safety

- New index columns: indexes-only DDL, non-destructive, safe with existing rows.
- `createdAt DEFAULT now()`: Postgres fills existing rows with the migration timestamp. No NULL values.
- `updatedAt`: Prisma generates this as `DEFAULT now()` in the migration SQL. Existing rows get migration timestamp.
- No column drops, renames, or type changes — expand-only, no contract phase needed.
