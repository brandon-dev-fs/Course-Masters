# Summary

There needs to be clean up and clearer structure of the lesson activities and student tools. Furthermore there should be additions to add a richer experience for students.

## Current Lesson Activities

Currently lessons are set up in the following way

- Lesson Plan (required not addable or removable only editable)
- Quiz (required not addable or removable only editable)
  and the following are for teachers to add
- Notes (Rich Text)
- Videos (YouTube Embedded)
- Reading (External Link)
- Vocab
- Practice Problems (A set of problems that can be multiple choice, T/F, Fill in the Blank, and Matching)

## Student Tools

Currently students have the following tools

- Notes
- Flash Cards
- Vocab
- Practice Problems

## Current Issues

- Students have vocab and flashcards these are functionally the same
    - Vocab should be removed from student tools in favor of flashcards
- No existing structure to easily add practice problems to student practice problems.
    - Remove the practice problems in favor of to be added study materials
    - students can always go back and revist practice problems

## Proposed updates

Changes to lesson activities

- Change reading (lesson activity) to external link
    - Evaluate feasability of page embedding to show the external page on lesson page instead of sending users out
- Add document upload and embedding
    - Users upload pdf or word doc and that document shows up in lesson page
    - This will require significant infrastructure lift and may need a seperate task
- Teacher should have functionality to add practice problems to quizzes and quiz problems to unit test. - These should be duplicates as teacher should be able to edit the questions seperately

Changes to student tools

- Remove all current but notes and flash cards
- Add activity bookmark
    - This will allow students to bookmark specific activities (notes, videos, etc.) to revisit
- Checklist
    - Creates a manual checklist of to do's
- investigate highlighter
    - students would highlight sections of notes or reading and it saves to revist
